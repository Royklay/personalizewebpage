 # Personalized Webpage

**Livelink:** https://royklay.github.io/personalizewebpage/


## Overview
This project is an interactive personalized webpage built using HTML, CSS, and JavaScript. It allows users to enter their name and age and displays a personalized greeting and age-related message.

## Features
- Accepts the user's name and age through a form.
- Displays a personalized greeting.
- Uses if...else statements to display messages based on age.
- Calculates the user's age in months.
- Displays a motivational quote five times using a for loop.
- Uses localStorage to save and retrieve the user's name and age.
- Includes CSS styling for a clean and user-friendly design.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or copy this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a web browser.
4. Enter your name and age, then click Submit.
